# Mobile App (Flutter Template)

Template ứng dụng Flutter starter tiêu chuẩn dành cho mobile.

## Yêu cầu môi trường
- Đã cài đặt [Flutter SDK](https://docs.flutter.dev/get-started/install) (phiên bản `>=3.0.0`).

## Hướng dẫn sử dụng

### 1. Cài đặt dependencies
```bash
flutter pub get
```

### 2. Chạy ứng dụng
```bash
flutter run
```

### 3. Chạy tests
```bash
flutter test
```
